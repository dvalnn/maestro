Ask of every changed file: a module, export or dependency that no requirement or plan item asks for? A duplicate of a
helper or pattern the codebase already has? An interface wider than the spec needs? A decision taken in code with no ADR
or owner ruling behind it? A function, module or wrapper whose deletion removes no complexity? A special case or flag
threaded through a shared module, where the module that owns the behaviour should change?

Ask of every doc the change touches or leaves describing changed code: does it say what the code now does?
